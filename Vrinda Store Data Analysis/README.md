# 📊 Vrinda Store Annual Report 2022 Dashboard

## 📌 Project Overview

This project analyzes the **Vrinda Store Annual Sales Report 2022** using Microsoft Excel.

The project includes data cleaning, Pivot Tables, Pivot Charts, Slicers, and an interactive dashboard to analyze sales performance, customer behavior, and business trends.

---

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis

---

## 📂 Dataset

- Vrinda Store Annual Sales Report 2022

---

## 📊 Dashboard Features

- Monthly Orders vs Sales
- Orders by Sales Channel
- Sales by Top 5 States
- Order Status Analysis
- Sales by Gender
- Orders by Gender
- Interactive Slicers
  - Month
  - Channel
  - Category

---

## 📈 Business Insights

- Women contribute **64%** of total sales.
- Amazon is the leading sales channel with **35%** of total orders.
- Maharashtra generated the highest sales (~₹2.99M).
- Around **92%** of all orders were successfully delivered.
- Adult customers placed the highest number of orders.
- Sales peaked around **March**, indicating stronger customer demand during that period.
